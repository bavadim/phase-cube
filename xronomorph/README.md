# Круг ритма — сбалансированное деление

Открыть `xronomorph/index.html`. Один редактор; прежние параметры `?mode=pb`,
`?mode=wf`, `?mode=tree` игнорируются. Это самостоятельный музыкальный
эксперимент; контракт основной игры `music-puzzle/3` не меняется.

## Инвариант и допустимые решения

Каждая атака инструмента — равная масса в точке единичной окружности.
Для каждого инструмента отдельно выполняется:

```
Σ exp(2πi t) = 0
```

Пустой инструмент молчит (сумма нулевая, центр тяжести не определён).
Одиночная нота запрещена. Центр тяжести непустого рисунка совпадает с центром
круга. Маркер в центре вычисляется из фактических координат нот.

Добавление сохраняет прежние ноты и создаёт сразу сбалансированную группу:

- **Пара:** `t`, `t + 1/2`.
- **Тройка:** `t`, `t + 1/3`, `t + 2/3`.

Время берётся по модулю одного цикла. Сумма векторов каждой группы равна
нулю, поэтому объединение групп сбалансировано. Произвольное вращение всей
партии умножает сумму на единичное комплексное число и также сохраняет ноль.
Баланс означает это геометрическое свойство; приятное звучание и музыкальная
законченность из него не следуют. Пары/тройки порождают полезное подмножество
PB-ритмов, а не все PB-фигуры (например, правильный пятиугольник ими не построить).

## Управление

Шесть инструментов начинают пустыми: бочка, хэт, бас, колокол, хлопок, щелчок.
Выбор — в палитре или по ноте соответствующего инструмента.

1. Выбрать «Пара · +2» или «Тройка · +3».
2. Нажать `+` в дуге либо потянуть его. Положение одной новой ноты определяет
   положение всех компенсирующих точек. Превью показывает группу целиком и
   подсвечивает все затронутые дуги. Данные и звук меняются при отпускании.
3. Если одна из точек накладывается на существующую ноту того же инструмента,
   превью краснеет, отпускание не меняет рисунок. Никакого удаления дубликатов
   или промежуточного состояния с одной новой нотой нет. Совпадения разных
   инструментов допустимы.
4. Тянуть любую ноту, чтобы вращать весь инструмент независимо от остальных.
5. Выбрать **«− Схлопнуть»**: на самой фигуре вместо плюсов появляются
   `−2`/`−3` для групп без потомков. Наведение/фокус выделяет затронутые ноты,
   нажатие убирает группу целиком. Затем можно схлопнуть её родителя и так
   вернуться к пустому инструменту. Это обратная операция к добавлению группы;
   остальные ноты и фазы не меняются. Перетаскивание `−`, отмена тача и Escape
   ничего не удаляют. Для добавления снова выбрать «Пара» или «Тройка».
6. В дереве можно удалить **целую ветвь с потомками**. Это отдельная
   возможность быстрого удаления; для обычного схлопывания дерево не требуется.

На пустом круге `+` создаёт первую пару/тройку. На непустом круге опорная
точка выбирается строго внутри выбранной дуги. Компенсирующие точки могут
попасть в другие дуги. По умолчанию выбирается середина; если она вызывает
совпадение, выбирается середина самого широкого допустимого участка.
Допустимые положения вычисляются аналитически исключением положений
`существующая нота − k / размер группы`.

Минимальное числовое расстояние между нотами — `1e-8` цикла, до 128 нот на
инструмент. В интерфейсе дополнительно запрещено накладывать центры маркеров
ближе 3 экранных пикселей; это учитывает округление сенсорных координат.
Содержимое дерева — история вложения групп: родителем новой группы становится
наименьший общий предок групп, ограничивающих выбранную дугу, либо новый
корень, если общего предка нет. Дерево не является деревом отдельных хорд.

Отмена: 48 музыкальных правок. Текущие темп, общая громкость, mute и выбор
пары/тройки при отмене сохраняются. Escape, отмена тача, потеря фокуса и уход
со страницы отменяют незаконченный жест. Клавиатура: Tab выбирает ноты и
операции, Enter/Space выполняет их; стрелки на ноте вращают инструмент на 1°,
Shift — на 10°.

Мышь/тач обрабатываются на постоянном корне SVG. Перерисовка детей не
удаляет цель касания. Кнопки активируются завершённым pointer-тапом, без
повторного совместимого click; скролл или отмена тача действие не выполняют.

## Формат и миграция

`balanced-rhythm/1` хранится в новом ключе `biba-balanced-rhythm/1`.
Партия содержит параметры звука, `phase`, счётчик `nextId` и дерево `groups`.
Обычный узел: `{id, kind:'orbit', order:2|3, at, children}`. Старые уже
сбалансированные фигуры импортируются неизменными атомами
`{id, kind:'fixed', points, children}`. Каждый узел и вся партия проходят
проверку нулевой суммы, уникальности нот и идентификаторов.

Если нового ключа нет, читается `biba-rhythm-arcs/1`, затем
`biba-xronomorph/1`. Переносятся только сбалансированные партии старого режима
вращения, включая прежние вложенные деления. Несбалансированные партии
в новом редакторе пусты; интерфейс сообщает об этом и позволяет скачать
**исходный JSON**. Их прежняя запись не перезаписывается. Сохраняются
инструменты, фазы, высоты, gate, velocity, mute, темп и громкость; недостающие
инструменты добавляются пустыми. Сохранённые дубли инструментов остаются
отдельными партиями. Миграция не притворяется исправлением старой музыки.

## Архитектура и проверки

`model.js` — чистая модель, дерево, разрешённые области, миграция;
`view.js` — SVG, связанное превью и жесты;
`app.js` — состояние, интерфейс, дерево и история.
`transport.js` сохранён: native Strudel 1.3.0 Pattern/Hap, Cyclist, Superdough,
локальные CC0-семплы и два встроенных синтезатора. Общий цикл не
перезапускается при редактировании. Собственный аудиопланировщик не добавлен.

Из родительского каталога:

```
node --test xronomorph/test.cjs
npm run check
BIBA_CHROMIUM=/path/to/chrome node xronomorph/browser.cjs
```

Модель: старт 0→2/3, связанные точки, точные совпадения и стык 0/1,
альтернатива недопустимой середине, дерево и удаление ветви, 600 смешанных
правок с проверкой баланса после каждого шага, независимое вращение,
миграция, ограничения и контракт музыкальных событий.

Браузер: мышь 1280×900 и native CDP touch 390×844, 844×390, 320×740;
связанные превью, красный запрет совпадения, баланс на каждом шаге жеста,
удаление ветви, схлопывание с фигуры до нуля, его отмена и клавиатурное
управление, undo, отмена жеста, сохранение/миграция/скачивание,
совпадение событий native Strudel с моделью и ненулевой PCM.
Отчёт `qa/balanced-report.json` содержит хеши проверенного исходного кода;
снимки — `qa/balanced-*.png`. Измерение PCM идёт через AudioContext с null
sink; это не авторское прослушивание и не тест физического iPhone.
