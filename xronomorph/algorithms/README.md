# Ритм: четыре задачи редактирования

Открыть `xronomorph/algorithms/index.html`. Это отдельная лаборатория,
не новый PB-режим или уровень `music-puzzle/3`. Песни и прежние сохранения не
изменяются. Короткие мотивы — диагностические примеры, не новые композиции.

Книжный ориентир: Emmanuel Amiot, [Music Through Fourier Space (2016)](https://link.springer.com/book/10.1007/978-3-319-45581-5),
главы 1–3 и 5, особенно §5.5.1 Fourier scratching. Реализация сверяется с
открытыми первичными публикациями; полное воспроизведение книги не заявляется.

| Редактор | Первоисточник | Готовый метод | Наша адаптация |
|---|---|---|---|
| Деформация мотива | [Amiot, Noll, Andreatta, Agon (2006), §2](https://www.researchgate.net/publication/228916245_Fourier_Oracles_for_Computer-Aided_Improvisation) | Комплексные события → DFT → изменение коэффициентов → IDFT | Плоские связанные виды, исходные мотивы, ограничение силы 2, жесты |
| Зеркало | [Beauguitte (2011), §1.6, стр. 10–11](https://www.atiam.ircam.fr/Archives/Stages1011/Beauguitte.pdf) | Реальная сила атак на сетке, отражение, сопряжение спектра | Симметризация усреднением с отражением, плавная смесь и выбор оси |
| Дополняющие партии | [Amiot, Sethares, §5](https://sethares.engr.wisc.edu/paperspdf/AlgofScales.pdf) | Замощение цикла сдвигами мотива, свёртка, спектральные нули | Exact-cover поиск на 16 шагах и интерактивные копии |
| Словарь мотивов | [Amiot, Sethares, §2 и §5](https://sethares.engr.wisc.edu/paperspdf/AlgofScales.pdf) | Сумма сдвигов словарных мотивов | Четыре семейства, минимальное дискретное разложение, затем ремикс |

Это разные пространства. В первом DFT применяется **по идентификаторам
событий**, в других данные — сила атак на временной сетке. Смысл одноимённых
коэффициентов между этими моделями переносить нельзя.

## Деформация мотива

```
z[j] = strength[j] exp(2πi onset[j])
a[k] = (1/N) Σⱼ z[j] exp(−2πijk/N)
z[j] = Σₖ a[k] exp(2πijk/N)
```

Угол выходного события — время, модуль — сила. При нулевом модуле событие
молчит, фаза не используется. Инструмент — отдельный параметр. Сохраняются
идентификаторы, но не обязательно хронологический порядок, интервалы или баланс.
Свободный жест меняет один коэффициент; остальные неизменны.

`|z[j]| ≤ 2` — наше ограничение динамического диапазона. Допустимая область
одного коэффициента есть пересечение дисков. Бисекция на отрезке от прежнего
значения останавливает двухмерный жест на границе. Ползунок фазы идёт по дуге,
сохраняет модуль и останавливается на первой границе. Модульный ползунок
сохраняет угол. Математическая декодируемость не гарантирует хороший ритм.
Нулевой a[0] означает баланс с исходными весами событий, а не равновесие
одинаковых масс на единичной окружности.

## Зеркало

16 сил `x[n] ∈ [0,1]`, отражение `Rx[n]=x[(m−n) mod 16]`:

```
y = (1−λ/2)x + (λ/2)Rx,  0 ≤ λ ≤ 1
Y[k] = (1−λ/2)X[k] + (λ/2) exp(−2πikm/16) conjugate(X[k])
```

Сумма сил и диапазон `[0,1]` сохраняются. При λ=1 это идемпотентная
проекция на зеркальные рисунки. Время не перемещается: меняются акценты и
паузы на фиксированных позициях. Доступны 16 осей, сохраняющих сетку;
плавная произвольная ось потребовала бы другой модели интерполяции. PB-баланс
из симметрии не следует.

## Дополняющие партии

Мотив `A ⊂ Z₁₆`, вступления `B`: `1_A * 1_B = 1` (циклическая свёртка).
Эквивалентно `|A||B|=16` и `Â[k] B̂[k]=0` для k≠0. Ручные правки допускают
пропуски и совпадения, показанные явно. Поиск выдаёт только точные покрытия.
Отказ относится к этому мотиву и периоду, не к любому музыкальному материалу.

Поиск исчерпывающий: первая непокрытая позиция, все содержащие её
непересекающиеся сдвиги, рекурсия. Сетка ограничена N≤16, без эвристического
таймаута. Производительность больших канонов Vuza не заявляется.
Начальный пример: `A={0,1,4,5}`, `B={0,2,8,10}`.

## Словарь мотивов

Семейства на Z₁₆: `{0}`, `{0,8}`, `{0,4,8,12}`, `{0,6,12}` (тресильо 6–6–4).
Двоичная цель разбивается динамической программой по оставшейся битовой маске
на минимальное число непересекающихся сдвинутых мотивов. Одиночные удары
гарантируют существование. Это **не общий вещественный L1-алгоритм** статьи:
на этапе разложения веса равны 1, отрицательные веса и наложения запрещены.

Далее возможен ремикс `y=Σ cⱼ Tᵦⱼmⱼ`: вращение задаёт один из 16 сдвигов,
радиус — `c ∈ [0,2]`. Совпадения складываются, не удаляются из суммы.

## Готовые инструменты, архитектура и звук

Сохранены pinned native `@strudel/web 1.3.0`, Cyclist, Pattern/Hap, Superdough,
локальные CC0-семплы и прежний `../transport.js`. В транспорт добавлены
необязательные `projection` и `sampleBase`; прежние значения по умолчанию
сохранены. Контракт головоломок не менялся; новый аудиопланировщик не написан.

Проверены имеющийся стек и опубликованный Mathematica-инструментарий статьи.
Подключать Mathematica или общий LP-оптимизатор в браузер ради 5–16 элементов
избыточно. Здесь DFT — прямая сумма максимум 256 слагаемых, дискретные поиски
ограничены 16 шагами. Это явные реализации узких задач, не универсальные
FFT/LP-движки. Vendor-файлы и их лицензии не изменены.

`model.js` — чистая математика/состояние; `view.js` — SVG и общие жесты;
`app.js` — интерфейс, история, A/B, локальное сохранение и звуковая проекция.
Воспроизведение меняет queried pattern, не перезапускает часы Cyclist.
Один оборот — такт 4/4, cps=BPM/240. Локатор и события используют общие часы.
Исходник и результат используют один выбранный инструмент.

На сетке выдаётся одна суммированная атака на позицию,
`velocity=min(1,strength/2)`. При сумме выше 2 график сохраняет истинную сумму,
динамика звука ограничивается. В scratching `velocity=|z|/2`, gain .1;
сеточные режимы используют gain .22. Master=100%. Для тихого локального
CC0-семпла claves фиксированный trim ×80 компенсирует уровень самого файла;
это не нормализация отдельных паттернов или акцентов. На исходном регулярном
мотиве до компенсации пики щелчка/хлопка были .000371/.03617.

Состояние `rhythm-methods/1` хранится отдельно от PB. Импорт проверяется до
применения, доступно 50 undo. Escape, pointercancel, blur, пауза и смена режима
отменяют жест. Pointer capture удерживает постоянный SVG, не перерисованные
дочерние узлы. На телефоне воспроизведение и A/B закреплены снизу.

## Проверки

Из `experiments/steel-shift-cube`:

```
npm run test:methods
node --test xronomorph/test.cjs
npm run check
BIBA_CHROMIUM=/path/to/chrome node xronomorph/algorithms/browser.cjs
BIBA_BROWSER=webkit node xronomorph/algorithms/browser.cjs
```

`test.cjs`: обратимость DFT/IDFT, реальные изменения времени/силы, тишина,
границы и модуль при повороте; отражение во времени/спектре, сумма и
идемпотентность; независимый полный перебор дополнений на малых циклах;
реконструкция по словарю; валидация сохранений и аудиопроекция.

`browser.cjs`: все редакторы, мышь и native CDP touch, cancel, клавиатура,
A/B, общие часы, совпадение actual native Strudel-событий с моделью,
ненулевой PCM, import/export, сохранение, четыре размера. `qa/browser-*.json`
содержит отпечатки исходников. Chromium null sink не доказывает звук из
динамика пользователя; WebKit не заменяет физический iPhone. Авторское
прослушивание и оценка музыкальной полезности остаются отдельной приёмкой.
