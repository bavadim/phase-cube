# Фурье-печать: реализованный эксперимент

Рабочая версия: `experiments/steel-shift-cube/index.html?puzzle=fourier`.
Исходный UX-референс сохранён в `reference.html`. Это исторический макет без звука;
он не является реализацией музыкальной привязки.

## Что перенесено и что изменено

В референсе три комплексных коэффициента формируют контур высоты, который затем
округляется до нот произвольного банка. Для совместимости с существующими
композициями первая игровая версия использует два коэффициента и преобразует
время атак, сохраняя авторские высоты, тембры, динамику и длительности. Ноты не
синтезируются из радиуса. Контур в центре — поле управления ритмом, окружающее
кольцо — реальные текущие и целевые события. Это не спектр PCM-звука.

Игрок выбирает C₁, C₂ или перелив ↔. Нажатие слева/справа на самой печати выполняет
обратную/прямую операцию выбранного регулятора. Повторное нажатие на выбранный
регулятор работает так же. Можно пользоваться нижними стрелками. Подсказка
выбирает регулятор и направление; сам ход выполняет игрок.

## Группа

Состояние — целочисленный ID матрицы U из конкретной конечной подгруппы U(2).
Коэффициенты: c = U c₀, c₀ = (0.61 + 0.17i, 0.29 + 0.43i).

| Регулятор | Действие | Период |
| --- | --- | --- |
| C₁ / A | c₁ ← i c₁ | 4 |
| C₂ / B | c₂ ← i c₂ | 4 |
| Перелив / M | (c₁,c₂) ← ((c₁−c₂)/√2, (c₁+c₂)/√2) | 8 |

A и B коммутируют; A и M — нет. Все генераторы обратимы и сохраняют
|c₁|² + |c₂|². Замыкание этих конкретных матриц содержит 192 состояния;
программа перечисляет его и строит 576 неориентированных рёбер. Переходы во время
игры идут по таблице целочисленных ID, без накопления округлений. Численная
идентификация матриц при построении таблицы — с точностью 10⁻⁹; это проверенная
конечная модель, не сертификат формального доказателя. Подсказка — кратчайший
путь по полному графу. Третий произвольный коэффициент/смешивание не заявлены:
конечность такой расширенной группы нужно проверять заново.

## Музыкальная проекция

Для каждой из шести музыкальных деталей:

    δc = c − c₀
    f(δc,t) = Re(δc₁ exp(2πit) + δc₂ exp(4πit))
    t′ = (t + 0.025 f(δc,t + α)) mod 1
    α = id / (6 × 7)

t — нормированное время атаки в игровом периоде, α — фиксированное смещение
поля для музыкальной детали. В цели δc = 0: звучит исходная авторская композиция.
Порядок атак внутри каждой детали сохраняется циклически: модуль производной
добавленного смещения ограничен 0.57501 < 1. Перенос границы цикла допустим.
Все ноты аккорда одной детали на общей атаке сдвигаются вместе. Gate, note, sample,
velocity и прочие параметры события не меняются; фон продолжает исходную песню.

Частоты 1 и 2 здесь означают одну и две волны за игровой период, не герцы
аудиосигнала. Максимальная амплитуда смещения ограничена выбранной нормой,
а не субъективной оценкой гармонии. Ритм может стать свободнее исходной сетки.
Технически корректные события не доказывают приятный грув, отсутствие маскировки
фоном или пригодность сложности для казуальной аудитории.

Анимация печати непрерывно проходит по унитарному пути; звук обновляется общей
транзакцией транспорта на ближайшей допустимой музыкальной границе. Плавная
анимация не означает непрерывное скольжение всех звучащих нот.

## Общая инфраструктура

Подробный контракт — `experiments/steel-shift-cube/CONTRACTS.md`.
Музыкальные композиции сохраняют `music-composition/1`. Головоломки v1 оставлены
с прежней таблицей фаз. Новый v2 описывает семейство проекции и число музыкальных
фрагментов отдельно от числа параметров прогресса. Оба семейства возвращают
`music-projection/1`: native Strudel patterns, события и признаки совпадения с целью.
Одинаковая группа симметрий им не требуется. Автономный экспорт содержит оба пути.

Проверки: `test-fourier.cjs`, `qa/fourier/contracts-report.json`,
`qa/fourier/browser-report.json`, общие регрессии в `qa/modules/` и `qa/three/`.
Состояние PASS нужно читать в актуальном отчёте, с соответствующими хешами;
акустическая и художественная приёмка остаются отдельными.
