# Фурье-точки: действующая версия

Рабочая версия: `experiments/steel-shift-cube/index.html?puzzle=fourier`.
`reference.html` — исторический UX-макет без звука. Старый вариант с двумя
коэффициентами и переключателями C₁/C₂/↔ заменён точечной диаграммой.

## Управление

На общей комплексной плоскости четыре заполненные точки-коэффициента 1–4.
Пустые цветные круги с теми же номерами обозначают целевые положения. Номера
целей вынесены наружу, чтобы их было видно, когда цель занята другой точкой.

Тап выбирает точку, выделяет её и соседнюю по номеру. Видимая связь и подпись
на нижней панели показывают выбранную пару: 1–2, 2–3, 3–4 или 4–1. Повторный
тап только выбирает; две нижние стрелки выполняют прямой и обратный ход пары.
Внутри диаграммы нет кнопок операций. Подсказка выбирает связь, выделяет нужную
нижнюю стрелку и показывает траектории обеих точек. Наведение даёт тот же прогноз.
Ввод остаётся общим Pointer/Raycaster, области выбора — не меньше 46 CSS px;
при пересечении областей выбирается ближайший центр.

Три стартовых хода используют разные связи, затрагивают все четыре точки и
показываются примерно за секунду. Все четыре цели после такого перемешивания
не совпадают с текущими точками; кратчайшее решение требует трёх разных связей.
Субъективная понятность, интерес и сложность требуют плейтеста.

## Точная конечная модель

Опорные коэффициенты:

    c₀ = (0.52, −0.32+0.32i, −0.40i, 0.30+0.30i)

X точки — действительная часть коэффициента, Y — мнимая. Это коэффициенты
временных гармоник, а не отдельные ноты или инструменты.

Для пары a,b прямой ход:

    (cₐ,cᵦ) ← (−cᵦ,cₐ)

Обратный ход:

    (cₐ,cᵦ) ← (cᵦ,−cₐ)

Остальные две точки не меняются. Все четыре генератора имеют период 4.
Непересекающиеся пары коммутируют, соседние — нет. Общая сумма |cₖ|² сохраняется.
Состояние — ID одной из 192 перечисленных знаковых перестановок с определителем
+1. Правила и переходы целочисленные: накопления погрешности в состоянии нет.
Полный граф имеет 768 неориентированных рёбер и диаметр 5. Подсказка использует
кратчайший путь по графу; это проверенная конечная модель, не Lean-сертификат.

Для анимации используется непрерывный путь, θ от 0 до ±π/2:

    cₐ(θ) = cos(θ)cₐ − sin(θ)cᵦ
    cᵦ(θ) = sin(θ)cₐ + cos(θ)cᵦ

Поэтому обе точки движутся согласованно и гладко, сохраняя общую норму. Эти
траектории не обязаны быть окружностями вокруг начала комплексной плоскости.
Значки нижних стрелок обозначают прямой/обратный ход, а не обещание одного
экранного направления для обеих точек при любой конфигурации.

## Музыкальная проекция

Для каждой из шести музыкальных деталей:

    δc = c − c₀
    f(δc,t) = Re(Σₖ₌₁⁴ δcₖ exp(2πikt))
    t′ = (t + 0.012 f(δc,t + α)) mod 1
    α = id / (6 × 7)

В цели δc=0 и звучит исходная авторская композиция. Частоты 1–4 означают волны
за игровой период, не герцы аудиосигнала. Порядок атак внутри каждой детали
сохраняется циклически: производная смещения ограничена
`0.012 × 2π × sqrt(1²+2²+3²+4²) × 2||c₀|| < 1`.
Gate, note, sample, velocity, число событий и остальные параметры не меняются;
фон продолжает исходную песню. События меняются общей транзакцией транспорта,
а не непрерывным аудио-скольжением вместе с анимацией. В быстром перемешивании
промежуточные звуковые состояния могут объединяться; финальное применяется
перед выдачей управления. Символьная различимость не доказывает приятный грув
или слышимость каждой правки в полном миксе.

## Контракты и проверка

Манифест: `music-puzzle/2`, id `fourier`, version 2, `fourier-time/2`,
четыре единицы прогресса и шесть музыкальных фрагментов. Version/проекция
изменены, поэтому старый кеш `fourier-time/1` не используется. Текущая реализация
не воспроизводит старые ID состояний двухкоэффициентного варианта.

Композиции сохраняют `music-composition/1`; оба семейства головоломок возвращают
`music-projection/1`. Кубик и плитки сохраняют свою фазовую привязку.

Проверки: `test-fourier.cjs`, `qa/fourier/contracts-report.json`,
`qa/fourier/{chromium,webkit}-points-report.json`. Браузерный прогон проверяет
выбор каждой точки во всех 192 состояниях, нижние операции, повторный тап,
три композиции, подсказку/отмену/паузу/перемотку, победу/повтор и автономный HTML.
Отчёты имеют хеши исходников. WebKit на Linux не заменяет физический iPhone;
художественная и музыкальная приёмка остаются за автором.
