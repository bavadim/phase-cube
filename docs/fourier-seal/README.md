# Фурье: общий циферблат, фаза и модуль

Текущая реализация: `experiments/steel-shift-cube/index.html?puzzle=fourier`.
`reference.html` — исторический UX-макет. Предыдущие парные операции заменены
независимым редактированием четырёх коэффициентов на одной комплексной плоскости.

## Правила и управление

Каждый коэффициент c[k] = A[k] exp(i φ[k]) показан стрелкой из общего центра:
угол — фаза из 8 положений, длина — модуль из {0,2; 0,4; 0,6}. Номер k обозначает
временную гармонику, не инструмент и не ноту. Цвет/номер закреплены за k.

Тап выбирает наконечник. Четыре постоянных номерных метки внутри модели дают
выбор, когда несколько стрелок совпали. Пустой круг показывает только цель
выбранного коэффициента. Операционных кнопок внутри модели нет.

Контракт модели возвращает список actions с id, названием, иконкой (текст/картинка),
callback, доступностью и необязательным прогнозом. Общая панель делит список
ceil(N/2) / floor(N/2) по сторонам от одной подсказки. Фурье задаёт слева ↶/↷,
справа −/+. У границы радиуса соответствующая кнопка недоступна. Rubik/Twiddle
используют тот же компонент с одним поворотом с каждой стороны. На узком боковом
блоке группы переносятся, логика поля не определяет раскладку HTML.

Наконечник можно перетаскивать мышью или пальцем. До отпускания модель/звук
не меняются: поле следует за указателем, эквалайзер показывает прогноз ближайшего
дискретного состояния. После отпускания угол и модуль привязываются к сетке,
обе координаты записываются одним ходом и одной транзакцией звука. Отмена
восстанавливает обе. Pointercancel, blur, потеря захвата, пауза и смена поля
отбрасывают незавершённый жест. Отдельных DOM-подписок и rAF в поле нет.

Модель создаётся собранной; три стартовых хода чередуют изменение фазы и модуля.
Игрок видит каждый шаг примерно за секунду. Стартовый показ не является
историей отмены. Подсказка выбирает коэффициент и выделяет доступную кнопку.

## Дискретная модель

Фазы цели: 0°, 135°, 270°, 45°. Модули цели: 0,6; 0,4; 0,4; 0,2.
Состояние — целый ID в (8 фаз × 3 радиуса)^4, всего 331 776 состояний. Цель — 0.

Поворот изменяет только фазу выбранного k на ±π/4, сохраняя модуль; период — 8.
Шаг радиуса меняет только уровень на ±1; на концах он не определён, а не
перескакивает к другому краю. Обратный шаг после любого допустимого существует.
Это произведение циклов и отрезков, не одна группа глобальных вращений.

Прямой жест — `{kind:'coefficient',key,from:{phase,level},to:{phase,level}}`.
Декодер проверяет from против текущего состояния; устаревший/пустой жест не
применяется. Инверсия меняет from/to местами. Каждый новый звук рассчитывается
по текущему состоянию, без накопления ошибок или зависимости от истории.

Расстояние по кнопкам — сумма кратчайших фазовых расстояний и различий уровней.
Подсказка уменьшает его на 1. Это не кратчайший решатель при разрешённых
произвольных перетаскиваниях: жест может заменить несколько кнопочных ходов.

## Музыкальная проекция

Для каждой из шести деталей авторского паттерна:

    δc[k] = c[k] − c₀[k]
    f(δc,t) = Re(Σ[k=1..4] δc[k] exp(2πikt))
    t′ = (t + 0.012 f(δc,t + α)) mod 1
    α = id / (6 × 7)

Первая гармоника даёт одну волну за период, четвёртая — четыре. Модуль определяет
вклад волны; фаза — её положение. В цели δc=0 и звучит исходная композиция.
Меняются только моменты атак. Ноты, тембры, velocity, gate и число событий
сохраняются. Фон продолжает исходную песню. Это временная модуляция паттерна,
не FFT аудио и не регулятор громкости инструмента.

Для всего допустимого диапазона (и непрерывного предпросмотра жеста):

    |d(t′−t)/dt| ≤ 0.012 × 2π × Σ k(0.6 + |c₀[k]|) < 1

Поэтому порядок атак внутри детали сохраняется циклически. Ограничение не
сертифицирует музыкальную выразительность, слышимость в миксе или интерес игры.
Модуль 0 не используется; при его добавлении фаза нулевого коэффициента не
должна учитываться при проверке победы.

## Контракты и проверка

Манифест: music-puzzle/2, version 3, fourier-time/3, четыре единицы прогресса,
шесть музыкальных фрагментов. Music-composition/1 и общий music-projection/1
не изменены. Кеш прежних Фурье-проекций не используется.

При загрузке — ограниченная выборка, включая 24 положения каждого коэффициента
по отдельности. Полный перебор всех 331 776 состояний в браузере не выполняется;
coverage=sampled фиксирует границу проверки различимости.

Проверки: test-actions.cjs, test-fourier.cjs, qa/polar/browser.mjs,
qa/three/layout.mjs и общие регрессии ввода/перемешивания/восстановления.
Отчёты содержат хеши текущих исходников. WebKit на Linux не заменяет физический
iPhone; художественная, игровая и музыкальная приёмка остаются за автором.
