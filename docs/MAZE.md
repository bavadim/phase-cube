# Звучащий лабиринт

Запуск: `index.html?puzzle=fourier&song=turkish-circuit`. Это новая геометрическая
реализация прежней головоломки с офисными креслами. ID `fourier` сохранён,
композиции и музыкальная проекция `complex-riff/3` используются прежние.

## Действия игрока

На общей подставке стоят шесть цветных восьмиугольных платформ с угловыми
дорожками. Между ними расположены семь неподвижных мостов с квадратными
опорами, зелёный вход и золотой выход. Огонёк проходит доступную часть пути
и останавливается у первого разрыва.

Каждая платформа управляет одним рифом. Выбор — нажатием на саму модель или
общей кнопкой следующего объекта. Горизонтальное перетаскивание поворачивает
дорожку, вертикальное поднимает её. Перетаскивание стойки сразу включает подъём.
Нижняя панель остаётся общей: два поворота, выбор объекта, подсказка и два подъёма.
На вращение отведено восемь положений с шагом 45°, на высоту — пять уровней
громкости: 0%, 50%, 100%, 150%, 200%. Высота округляется уже в прогнозе;
отпускание фиксирует один обратимый ход. Отмена возвращает обе координаты.

Фаза сдвигает музыкальную партию относительно её настоящего периода; подъём
умножает громкость. Ноты, их порядок, тембры, длительности и динамика внутри
исходного рифа сохраняются. Эквалайзер показывает ту же партию и тот же ход.
У каждого узла есть постоянная высота основания: при 100% он стыкуется со
своими мостами. Поэтому мосты могут подниматься и спускаться по террасам.

## Геометрическая цель

Вход и выход соединены единственной цепью через все шесть подвижных платформ.
У каждого подвижного участка два порта под прямым углом. Поворот на 180°
не сохраняет эти два стыка. Полный оборот возвращает исходный рисунок.

Для каждой пары торцов проверяется совпадение настоящих координат X, Y, Z.
Эти контакты добавляются в граф. Достижимость выхода от входа вычисляется
обходом графа; `Model.solved()` использует именно эту проверку.

Для данной цепи и её разрешённых состояний:

```
выход достижим
  ⇔ оба стыка каждого из шести узлов соединены
  ⇔ у всех рифов целевая фаза (mod 2π) и громкость 100%
  ⇔ звучит авторская композиция
```

Проверены все 240 отдельных положений (6 × 8 углов × 5 высот). Для каждого
узла представлены все четыре возможных типа интерфейса: нет контактов,
только вход, только выход, оба контакта. Перебраны все 4096 сочетаний этих
типов (4^6). Отчёт: `qa/maze/contracts-report.json`. Это проверка данной
геометрии и музыкальной привязки, не оценка художественного качества или звука.

При создании разветвлённого лабиринта, обходных путей или других типов дорожек
это соответствие нужно проверять заново: одной физической связности может
оказаться недостаточно для однозначного музыкального решения.

## Разделение кода

- `puzzles/fourier/maze.js` — точки, порты, мосты, трасса и граф достижимости.
- `puzzles/fourier/maze-model.js` — допустимые состояния, пять высот, ходы,
  подсказки, обратимость и геометрическая победа. Использует общий комплексный
  базис `model.js`, не меняя правил других головоломок.
- `puzzles/fourier/three-view.js` — только Three.js, жесты и визуальная обратная
  связь. Порты модели и мировые координаты представления проверяются отдельно.
- `module.js` — манифест `music-puzzle/3`, название и фабрика модели.
- Общие `PuzzleControl`, `PuzzleStage`, панель кнопок, аудиотранспорт и эквалайзер
  используются без отдельной ветки приложения.

Новый вид музыкальной проекции или новый контракт компонентов не требуются.
Манифест Фурье обновлён до версии 8 и сообщает суженный домен пяти амплитуд.
Подготовка и кеш привязок учитывают эту версию. Модель старого кресла и его
визуальные элементы заменены; общий математический комплексный базис оставлен.

## Воспроизводимые проверки

```
node check.mjs
node --test test-maze.cjs test-fourier.cjs test-bounce.cjs test-shuffle.cjs test-components.cjs test-actions.cjs test-pointer.cjs test-focus.cjs
MAZE_SIZE=1280 node qa/maze/browser.mjs
MAZE_SIZE=390 node qa/maze/browser.mjs
node export.mjs
node qa/maze/offline.mjs
```

Браузерные проверки включают выбор всех шести узлов при разных высотах,
сравнение портов с реальными преобразованиями Three.js, мышь/тач, независимые
жесты фазы и подъёма, прогноз одной партии, отмену, подсказки и окно победы.
Отчёты привязаны к хешам исходников. WebKit-эмуляция не заменяет физический iPhone.
