# Собери грув — Phase Cube

Музыкальная головоломка: настоящие повороты кубика 2×2 меняют фазы восьми фраз
Strudel. Сравни текущий рисунок с целью и собери композицию.

Полностью клиентское приложение: HTML, CSS и JavaScript. Бэкенда, сборщика,
CDN и обязательных npm-зависимостей нет. Все звуки и библиотеки локальные.

## Запуск

Открыть `index.html` в браузере либо отдать каталог любым статическим сервером.
GitHub Pages публикует эти же файлы без сборки. В URL собственных CSS/JS
указана ревизия `?v=2`, чтобы обновление не смешивалось с браузерным кешем.
При следующем изменении этих файлов следует увеличить ревизию. Для передачи одним файлом:

```sh
node export.mjs
```

Результат — `phase-cube.html`. Node нужен только для проверок и экспорта,
в самом приложении он не используется.

## Управление

- Сверху **Прослушать цель**: включает образец ещё до старта. Повторное нажатие
  останавливает образец; во время игры возвращает к текущему миксу.
- **Начать** в окне над моделью запускает игру и текущую музыку.
- Снизу ровно три действия: **Перемешать**, **Подсказать**, **Пауза**.
  Пауза выключает звук, сохраняет кубик и блокирует ходы. Продолжение — кнопкой
  в окне или в нижней панели; короткий звуковой цикл запускается заново.
- На компьютере левая половина плитки — обратный поворот, правая — прямой.
  На телефоне касание выбирает грань, а две кнопки 44×44 под кубиком выполняют
  поворот. Селектор между стрелками позволяет выбрать и скрытую сторону.
  Потянуть кубик — осмотреть. Камера не меняет музыкальное состояние.
- U/R/F/D/L/B и Shift + буква — прямые/обратные ходы; эти же подписи работают
  как кнопки. Пробел — старт/пауза, S — соло партии, Ctrl Z — отмена хода,
  Esc — отмена подсказки. Все инструкции открыты постоянно.
- Подсказка показывает грань и стрелку; ход выполняется нажатием нужной стрелки
  либо плитки. Подсказка использует сохранённый путь, а не кратчайший решатель.
- При полной сборке проигрывается короткий CSS-салют. Он не блокирует
  управление, удаляется после завершения и учитывает prefers-reduced-motion.
- Выбор кольца/имени выделяет партию. В карточках есть solo/mute; на узком экране
  они заменены одной строкой выбора партии и её переключателями.

## Музыкальное сравнение

Сплошные дуги — текущие события, полые контуры — цель, поперечные отметки — атаки.
Один оборот — один цикл 4/4; 144 BPM по умолчанию. Дуги — длительности событий
`queryArc`, а не измерения физического затухания WAV. Аккорды показаны параллельными
линиями, переход через начало круга сохраняет продолжение события.

Наведение на половину плитки или фокус на кнопке поворота выделяет затрагиваемые
партии. Пунктир показывает рисунок после хода, остальные кольца приглушаются,
сохраняя позиции. Прогноз строится на копии cubejs и настоящих событиях Strudel,
не меняет модель и не ставит звук в очередь. Сдвиг на собственный период фразы
не считается изменением её событий. Это структурная проверка, не модель восприятия.

Повороты и смена микса звучат на ближайшей границе такта. До неё отображается
слышимая версия; новый прогноз временно скрыт. Последняя правка заменяет ожидающую,
не откладывая границу. Пауза немедленно закрывает мастер-шину, очищает очередь
и затем приостанавливает AudioContext. Включение/выключение цели до старта
не начинает игровую сессию. Темп меняется при выключенном звуке. Мастер имеет фиксированную калибровку
`outputGain=4` (+12,04 дБ); ползунок 0–100% управляет её долей. Уровни инструментов
не менялись. Значение ползунка, выбранное во время инициализации, сохраняется.

## Телефонная раскладка

На узких экранах и телефонах в альбомной ориентации цель закреплена сверху,
три игровых действия — снизу. Учитываются safe-area-inset со всех сторон;
клавиатурные инструкции и настройка темпа скрыты. Селекторы имеют шрифт 16 px,
основные кнопки — цель касания не меньше 44 px. Прокручивать страницу можно
вне области осмотра кубика. Canvas ограничен pixel ratio 2.

Проверены размеры 320×568, 390×844, 393×852, 402×874, 430×932 и 852×393
в Chromium. Это проверка адаптивной раскладки и событий указателя, не запуск
на физическом iPhone/Safari. Реальные Safari, аудиовыход, вырез экрана,
панели браузера и жесты iOS требуют отдельной проверки на устройстве.

## Структура

| Файл | Ответственность |
| --- | --- |
| `index.html`, `style.css` | Разметка и адаптивное оформление |
| `app.js` | Связывает UI, сессию, модель, музыку и сцену |
| `session.js` | Переходы ready / playing / paused и режим прослушивания |
| `config.js` | Дизайнерские настройки, инструменты и исходные фразы |
| `model.js` | Состояние углов cubejs, ходы, фазы, решение |
| `music.js` | Настоящие Strudel-паттерны, события и прогнозы |
| `transport.js` | Транзакции на границах тактов поверх Cyclist/Superdough |
| `cube-view.js` | Three.js-сцена и анимации |
| `cube-input.js` | Raycaster, выбор грани касанием, мышиные ходы и подсказки |
| `celebration.js` | Однократный запуск и очистка CSS-салюта |
| `orbit.js` | Кольцевое SVG-представление событий |
| `samples.js`, `vendor/` | Встроенные семплы и закреплённые библиотеки |

Классические скрипты с явным порядком подключения сохраняют работу через `file://`.
Сторонние библиотеки не переписаны. Изменение музыкальных фраз не было частью
рефакторинга. Диагностика и инспекционный API включаются только с `?debug=1`;
служебных панелей в интерфейсе нет.

## Проверка

```sh
node check.mjs
node --test test-model.cjs test-session.cjs
```

`check` проверяет синтаксис клиентских скриптов, уникальность HTML id и отпечатки
vendor-файлов. Тесты отдельно проверяют модель кубика и переходы игровой сессии.
Нативные Strudel/transport-проверки: `test-orbit.mjs`, `test-transport.mjs`
(нужен установленный `@strudel/core`; в браузере он уже включён в bundle).
Браузерная проверка `client-app/2` сохраняется локально в
`qa/mobile-audio-report.json`. `qa/client-report.json` относится к первой редакции.
Отдельно выполнен нативный OfflineAudioContext-рендер 20 состояний для
калибровки пиков и RMS; это проверка сигнала, а не LUFS или музыкальная приёмка. Исторические отчёты и служебная диагностика не входят в публикацию.

## Соответствие кубика музыке

У детали `i`, занимающей гнездо `j` с ориентацией `o`:

```text
delta = ((3*j + 8*o - 3*i) mod 24) / 24
sound = stack(fixed_kick, phrase[i].late(delta), ...)
```

Цвет наклейки обозначает сторону, номер — музыкальный объект. Используется действие
cubejs на восьми углах с фиксированной системой координат; камера не является ходом.
Победа проверяется по полной сборке углов. Симметричные ритмы могут звучать одинаково
в разных состояниях. Универсальная гармоничность всех состояний не доказана.

Материал — восемь коротких исходных мотивов проекта: C/G-бас и лид, ответы G5/C5,
аккорд Cm7, шумовой удар, хэты и басовый пульс; опорная бочка неизменяема.
Sine/triangle/sawtooth/square/white синтезируются Strudel; встроены два коротких
WAV: kick 0,22 с и hat 0,07 с. Полной записанной песни здесь нет.
Это эксперимент, не принятый музыкальный уровень Godot. Технические проверки
не удостоверяют художественное качество или звук на физическом устройстве.

Трёхминутная аранжировка возможна с общими фазовыми параметрами и коротким окном
сравнения; независимое редактирование каждого такта в текущую модель не входит.
2–3 управляемых инструмента с фиксированным фоном остаются отдельным направлением:
потребуются распределение мотивов, проверка слышимости ходов и музыкальной цели.
