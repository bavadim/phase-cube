# Музыкальный кубик — Strudel-композиции

Кубик 2×2 преобразует фазы восьми нотных паттернов. Проигрывается вся песня;
кольцевой рисунок использует короткий период партий игрока. Фон — отдельный
Strudel-паттерн на собственной неизменной шине. Поворот заменяет только игровые
голоса на общей доле, сохраняя музыкальную позицию и продолжающиеся звуки фона.

На старте можно выбрать «Моцарт на конвейере», «Цех горного короля» или
«Элиза после смены». `?song=steel-shift` открывает конкретную композицию.
Выбор в паузе начинает новую задачу с выбранной музыкой. Названия, темп,
длительность, информация результата и ссылка скачивания обновляются из модуля.

## Один музыкальный файл

`compositions/*.strudel.mjs` — обычные ES-модули, возвращающие живые Strudel
Patterns. Внутри каждого: мининотация, патчи/сведение, размещение фраз, форма,
название и **явный список `playerParts`**. Соседний JSON-конфиг не нужен. Экспорт `metadata` даёт каталогу названия и темп
без исполнения нот; паттерны и статистика строятся только при выборе трека.
Это исходники для редактирования; приложение не генерирует музыку из WAV.

```js
export const metadata = {
  title: 'Название', style: 'Rave', bpm: 150, download: 'assets/my-song.mp3'
};
export default function compose({note, cat, silence}) {
  const bass = cat(note('a2 ~ a3 ~'), note('f2 ~ c3 ~')).s('sawtooth');
  return {
    ...metadata, periodBars: 2,
    sections: [{name: 'A', bars: 8}, {name: 'B', bars: 8}],
    playerParts: [{key: 'bass', name: 'Бас', pattern: bass}],
    backing: silence
  };
}
```

`composition-loader.js` хранит только список путей каталога. Он загружает модуль
через `import()`, исполняет его с закреплённой библиотекой Strudel и строит:

- игровое описание `song.game`: восемь паттернов, названия/цвета деталей, период,
  нормализованные события и целевые дорожки для кольца;
- позиции секций и общую длину из формы; секунды из темпа и числа тактов;
- статистику атак, звучащих партий, тембров, периода и максимального gate через
  штатный `queryArc`, без второго музыкального парсера;
- проверку непустых деталей, повторяемости всех игровых периодов и возврата фона
  после всей песни. Неверный модуль отклоняется до запуска.

Период задан автором: из произвольной JS-функции Strudel нельзя надёжно вывести
минимальный период. Загрузчик проверяет заявленный период на всех повторах
авторской формы и на следующем обороте. Случайные генераторы для игрового слоя
не подходят без дополнительного фиксирования результата.

Физическая группа кубика имеет восемь деталей. По умолчанию они распределяются
между `playerParts` поровну, остаток — первым партиям. Три партии дают 3+3+2.
Ноты каждой партии распределяются по очереди по этим деталям, аккорд остаётся
вместе. Можно указать `pieces` явно и `split:'time'` для временных фрагментов.
«Цех» сохраняет восемь полутактовых участков риффа; «Моцарт» управляет басом,
металлическим риффом и щипковым ответом; «Элиза» — басом с sub, FM-риффом и acid.
В `backing` контролируемые партии не включены повторно.

Чтобы добавить трек: создать модуль и добавить его ID в список `files`
загрузчика. Остальной JS и HTML не требуют названий, нот, длительностей или
конфигов новой композиции. `config.js` содержит только оформление, громкость UI
и правила первоначального перемешивания.

## Звук и загрузка

`audio-bank.js` регистрирует небольшие исходные банки в Strudel и предварительно
декодирует нужные выбранной песне семплы. `assets/samples/` — отдельные удары и
мультисемплы инструментов; готовых фонов и нарезанного риффа в воспроизведении нет.
Транспорт использует upstream Cyclist/Superdough, `queryArc` и обычные Web Audio
шины. Синтезатор, часы и язык паттернов не переписаны.

Godot-источники в `levels/music/raves/` сохраняются. В browser Strudel патч
`supersaw` выражен через `sawtooth` с исходным `unison`; мастер Pedalboard в браузер
не перенесён. Ноты/тайминг «Моцарта» сверены с исходной партитурой для всех 2491
события. Живое браузерное звучание не объявляется побитной копией студийного WAV.

Скачивание MP3 использует ссылку в том же музыкальном модуле. Для «Моцарта» и
«Элизы» это подготовленные студийные версии из `output/music/`; для «Цеха» сохранён
прежний игровой MP3. MP3 не участвуют в воспроизведении или построении головоломки.
Историческая PCM-упаковка перенесена в `output/music/phase_cube_legacy_pcm/`.

## Запуск и автономный экспорт

```sh
python3 -m http.server 5193 --bind 127.0.0.1 --directory experiments/steel-shift-cube
```

Открыть http://127.0.0.1:5193/. Нет CDN, бэкенда или обязательного сборщика.
`node export.mjs` создаёт `steel-shift-cube.html` со всеми тремя модулями,
исходными банками и MP3 внутри. Загрузчик использует те же функции композиции;
экспорт не заменяет ноты аудиофрагментами. После изменения источников экспорт
нужно обновить.

## Проверки и интерфейс

```sh
node check.mjs
node --test test-model.cjs test-session.cjs test-compositions.cjs
node export.mjs
```

`test-compositions.cjs` исполняет закреплённый Strudel в V8 без аудиоустройств,
сверяет партитуру, разделение партий и вычисляемые данные. Это не браузерное аудио.
`qa/compositions/runner.html` — отдельная проверка загрузки всех треков, ходов,
сохранения фоновой шины, перемотки/паузы, полного оборота, победы и размеров.
Её отчёт — `qa/compositions/browser-report.json`; она не входит в основной экран.

Основная мобильная раскладка mobile6 сохранена: кубик с кольцом, перемотка,
выбор грани, две стрелки, отмена и пауза. Выбор композиции находится в модальном
экране начала/паузы. Поле выбора — 48 px, остальные цели касания — от 44 px.
Проверены Chromium viewport 320×568, 390×844 и 852×393. Это не физический iPhone
и не проверка Safari или художественной пригодности музыки.
