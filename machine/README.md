# Ночная смена — PoC собираемой музыкальной машины

Открыть `machine/index.html` через HTTP-сервер из корня эксперимента.
Например: `python3 -m http.server 5173 --bind 127.0.0.1`.
Основная страница головоломок остаётся в `../index.html`.

## Опыт и управление

Свободное составление ансамбля из существующих композиций. Нет перемешивания,
эталона, оценки правильности или победы. Музыкальный материал воспроизводит
локальный Strudel; запись MP3 исходного трека здесь не используется.

- Первый клик/тап выбирает устройство.
- Повторный клик по корпусу подключает или снимает деталь.
- Перетаскивание корпуса вверх/вниз меняет громкость.
- Ручка на детали меняет сдвиг: перетаскивание вращает её, повторное нажатие
  делает один шаг.
- Картридж с рисунком партии переключает фразу повторным нажатием.
- Нижние кнопки: отмена, следующая деталь, воспроизведение, подключение, фраза.
- Меню под названием композиции содержит выбор материала, A/B и сохранения.

Все звуковые изменения доступны на модели. Бокового инспектора, HTML-ползунков
и полки карточек нет. На сенсорном экране действия не зависят от hover.
Один законченный жест — одна запись отмены; отмена жеста не сохраняет изменение.

## Контракты

`mechanism/1` — отдельная модель свободного творчества. Она не притворяется
головоломкой `music-puzzle/3`: у неё нет solved/hint/shuffle и фиктивного эталона.
Существующий контракт игры не изменён.

| Файл | Ответственность |
| --- | --- |
| `model.js` | Чистое состояние деталей, допустимые значения, undo, нормализация сохранения |
| `music.js` | `mechanism-music/1`: извлечение фраз из `music-composition/1`, нативные Strudel Patterns и события |
| `three-view.js` | Один вид машины: геометрия, поверхности выбора, жесты, визуальная реакция на события |
| `controls.js` | Компактная панель, вызывающая те же действия модели |
| `app.js` | Загрузка, жизненный цикл, звук, очередь изменений, A/B и сохранения |
| `index.html`, `style.css` | Оболочка и адаптивная раскладка |

Переиспользованы исходные composition loader/contract, audio bank, transport,
PuzzleStage/Pointer и Resources. Библиотеки Three.js и Strudel уже локально
зафиксированы в vendor. Нового движка, парсера мининотации и синтезатора нет.
Вид использует общий контракт отображения Stage; игровых правил в renderer нет.

Все исходные инструменты распределяются между шестью устройствами. Деталь
может содержать несколько исходных голосов одной роли. Варианты — разные
непустые окна исходной композиции длиной `periodBars`; новые ноты не сочиняются.
Фон транспорта заменён тишиной: снятие всех деталей выключает весь ансамбль.

Поле `phase` — **восемь доступных сдвигов 0…7/8 одного такта**, а не полная
круговая фаза многотактовой фразы. Рисунки событий нормированы к `periodBars`.
Громкость 0–1.5 умножает исходный postgain, сохраняя динамику и тембр.
Полный ансамбль в базовых вариантах и нулевом сдвиге совпадает с исходным окном;
благозвучие произвольного смешивания других вариантов не гарантируется.

Изменения звука применяются общим транспортом на ближайшей доступной доле.
Пока одна транзакция ожидает исполнения, хранится последнее желаемое состояние:
непрерывный жест не откладывает применение бесконечно. Выбор объекта без изменения
музыки не перезапускает ноты.

Сохранение `mechanism-scene/1` содержит songId, состояние и варианты A/B.
Есть автосохранение, отдельная ручная копия и импорт/экспорт JSON. Это файл сборки,
не запись аудио. Музыкальная и художественная приёмка остаются за автором.

## Проверки

`node --test machine/test-model.cjs` — композиции доступного каталога, сравнение нативных
событий и длительностей, независимость деталей, undo/сохранения, тишина,
длинные ноты на шве цикла.

`node machine/test-browser.mjs` — браузерная проверка прямых жестов и звука.
Артефакты конкретного запуска находятся в `machine/qa/`. Эмуляция touch
не заменяет физический iPhone/Safari.
